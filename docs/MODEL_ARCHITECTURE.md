# Model Architecture

Nexum AI Core is model-independent at the runtime boundary and model-focused in the training layer.

## Layers

1. Inference abstraction
2. Context and memory
3. Reasoning and orchestration
4. Specialist agents
5. Tools and execution
6. Verification and evaluation
7. Training-data collection
8. Fine-tuning
9. Multimodal integration
10. Proprietary foundation model

## Target capability surface

The long-term model is intended to handle reasoning, software engineering, architecture, design, vision, research, tool use and long-horizon tasks.

## Grounding rule

The system must never claim a tool action, test, file change or external result that it did not actually observe.
